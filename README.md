# KONFOR Website
Static site: `index.html` + `images/` (WebP; thumbnails in `images/t`, full size in `images/f`).
Keep the folder structure when uploading. No build step.

VS Code: open folder > Live Server > Open with Live Server.
GitHub Pages: git init && git add . && git commit -m "KONFOR" && git branch -M main
git remote add origin https://github.com/USERNAME/konfor-site.git && git push -u origin main
Then Settings > Pages > Deploy from branch > main / root.
Edit product data in `const P=[...]` (n name, a Arabic, e English, z sizes). Phone: search 963991310740.
